# AirLingua

ローカル LLM を使った macOS 向け翻訳アプリ。右クリックメニューから即座に翻訳できます。

## 特徴

- **完全ローカル処理** - インターネット接続不要、プライバシー安全
- **右クリックで翻訳** - テキスト選択 → 右クリック → 「AirLingua: 日本語に翻訳」
- **メニューバー常駐** - 軽量でいつでもアクセス可能
- **複数モデル対応** - Gemma 4 / PLaMo 3 / Qwen3.5 / TranslateGemma / ELYZA / ALMA

## インストール

### Homebrew

```bash
brew tap fuwasegu/tap
brew install --cask airlingua
```

### 手動インストール

[Releases](https://github.com/fuwasegu/AirLingua/releases) から最新の ZIP をダウンロードして、`AirLingua.app` を `/Applications` に移動。

## 必要条件

- macOS 14.0 (Sonoma) 以上
- llama.cpp は同梱済み（別途インストール不要）

## 使い方

1. アプリを起動（メニューバーに常駐）
2. 設定からモデルをダウンロード
3. テキストを選択して右クリック →「サービス」→「AirLingua: 日本語に翻訳」

## 翻訳品質比較レポート (2026-04-12 更新)

PLaMo 3 Translate（8B / 2B / 0.8B）および Gemma 4 E4B を含む主要モデルの英日翻訳品質を比較した。

### テスト条件

- **量子化**: すべて Q4_K_M (GGUF)
- **比較モデル**:
  - PLaMo-3-translate 8B (~5.3 GB) / 2B (~1.8 GB) / 0.8B (~0.6 GB)
  - Gemma 4 E4B (~5.0 GB)
  - Qwen3.5-9B (~5.9 GB) / Qwen3.5-4B (~2.9 GB)
  - TranslateGemma-4B (~2.5 GB)
- **実行環境**: AirLingua（`llama.cpp`、`temp=0.1, repeat-penalty=1.1`）※Gemma 4 E4B は同等のプロンプト設定

### 総合結果

| 順位 | モデル | サイズ | Text A | Text B | Text C | 総評 |

| **1** | **PLaMo-3-translate 8B** | 5.3 GB | **S** | **S** | **S** | 全カテゴリで最高評価。特に口語・イディオムと自然な日本語表現力が圧倒的 |

| **3** | **PLaMo-3-translate 0.8B** | **0.6 GB** | **A+** | **S-** | **A** | **驚異のコスパ**。わずか 0.6 GB で 6 GB 級の汎用モデルを凌駕し、高速・省メモリ |
| **4** | **PLaMo-3-translate 2B** | 1.8 GB | **A** | **A+** | **A+** | 軽量ながら口語・抽象表現ともに 8B に迫る高い完成度 |
| 5 | Qwen3.5-9B | 5.9 GB | B | B- | B- | 口語の雰囲気は良いが、二重否定ミスと訳語ムラ |
| 6 | TranslateGemma-4B | 2.5 GB | B+ | C | B | 翻訳特化のわりに口語で誤訳。技術文書は安定 |
| 7 | Qwen3.5-4B | 2.9 GB | F | C+ | B+ | Text A で中国語出力は致命的 |

**結論**:
- **品質最優先（個人利用）**: **PLaMo-3-translate 8B** が技術文書・口語・抽象表現のすべてで S 評価を獲得。英語特有の二重否定やイディオム（`where they're coming from`, `half-baked`, `call it a day`）、代名詞の省略まで含めて、最も「翻訳臭のない自然な日本語」を出力する。
- **速度・省メモリ最優先**: **PLaMo-3-translate 0.8B**（約 0.6 GB）が驚異的。約10倍のサイズがある Qwen3.5-9B（5.9 GB）を全テストで上回り、常駐翻訳アプリとしてのレスポンス速度と品質のバランスが抜群。
- **商用・業務利用**: PLaMo Community License は個人・非商用利用限定のため、業務利用では Apache 2.0 ライセンスかつトップクラスの品質を持つ **Gemma 4 E4B** が最適。
